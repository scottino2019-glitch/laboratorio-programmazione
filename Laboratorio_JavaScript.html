Le Basi: Variabili e Testo Dinamico

Variabili & Template Literals

Una variabile è come una scatola con un'etichetta dove puoi conservare informazioni (numeri, parole, dati). In JavaScript moderno usiamo let se il valore può cambiare, o const se il valore rimane fisso.

  • const: Valore costante che non cambia nel tempo.
  • let: Valore che può essere riassegnato (es. un contatore).
  • Template Literals (`...${}`): Ti permettono di inserire variabili direttamente nel testo usando i caratteri di accento grave backtick.
const nomeUtente = "Marco"; const messaggio = `Ciao ${nomeUtente}! Benvenuto in JavaScript.`; output.innerHTML = `<h1>${messaggio}</h1>`;

Il DOM: Scrivere e Cambiare la Pagina

DOM & Stili

Il DOM (Document Object Model) è il ponte tra JavaScript e l'HTML. Permette a JavaScript di leggere, modificare o aggiungere elementi e colori alla pagina in tempo reale.

  • document.getElementById("mioId"): Trova un elemento nella pagina usando il suo attributo id.
  • elemento.innerHTML: Sostituisce il contenuto HTML all'interno dell'elemento.
  • elemento.style.background: Modifica lo stile CSS al volo!
const scatola = document.getElementById("box"); scatola.style.background = "#38bdf8"; scatola.innerHTML = "<p>Colore cambiato con successo!</p>";

Gli Eventi: Rispondere ai Click dell'Utente

Eventi & Interattività

I programmi prendono vita quando rispondono alle azioni dell'utente: click, digitazione sulla tastiera, o passaggio del mouse. Usiamo addEventListener("click", funzione) o bottone.onclick.

  • Un contatore tiene traccia dei click aumentando una variabile numerica ad ogni tocco.
  • La funzione viene eseguita solo quando il pulsante viene cliccato.
let conteggio = 0; const bottone = document.getElementById("mioBottone"); bottone.onclick = function() { conteggio = conteggio + 1; document.getElementById("display").innerText = conteggio; };

Array e Oggetti: Organizzare Dati e Liste

Array & JSON

Un Array [...] è una lista ordinata di elementi. Gli Oggetti {...} contengono coppie di proprietà con chiavi e valori (come una scheda anagrafica).

  • array.forEach(...): Scorre ogni elemento della lista uno per volta.
  • document.createElement("div"): Crea un nuovo elemento HTML direttamente dal codice.
const frutti = ["Mela", "Banana", "Arancia"]; frutti.forEach(frutto => { const riga = document.createElement("li"); riga.textContent = `Frutto: ${frutto}`; lista.appendChild(riga); });

Filtri e Ricerca: Trovare Elementi al Volo

Metodo .filter()

Nei siti web moderni, come i motori di ricerca o i negozi online, vogliamo mostrare solo i risultati che corrispondono a ciò che l'utente scrive. Usiamo .filter() combinato con .includes() e l'evento input.

const parole = ["Gatto", "Cane", "Casa", "Albero"]; // Filtra le parole che contengono il testo cercato const risultato = parole.filter(p => p.toLowerCase().includes("ca")); // risultato contiene: ["Cane", "Casa"]

LocalStorage e JSON: Salvare i Dati nel Browser

Persistenza dei Dati

Quando chiudi o ricarichi una scheda normale, le variabili JavaScript vengono resettate. Con localStorage puoi salvare note, task e impostazioni nel browser dell'utente così rimangono memorizzate per sempre!

  • localStorage.setItem("chiave", testo): Salva un dato.
  • localStorage.getItem("chiave"): Recupera il dato salvato.
  • JSON.stringify(array): Trasforma un array o oggetto in una stringa di testo.
  • JSON.parse(stringa): Ritrasforma la stringa nel formato originale (array o oggetto).
// Salvataggio const spesa = ["Latte", "Pane"]; localStorage.setItem("lista", JSON.stringify(spesa)); // Recupero const recuperata = JSON.parse(localStorage.getItem("lista") || "[]");
